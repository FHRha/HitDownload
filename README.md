# HitDownload (hitdl)

HitDownload — это мощная и красивая консольная утилита для быстрого и многопоточного скачивания музыки с Яндекс Музыки, YouTube и зеркал Hitmo (rus.hitmos.fm и др.). Она автоматически парсит страницы, скачивает треки, прописывает правильные MP3-теги (ID3) и раскладывает их по папкам в структуре `Исполнитель / Альбом / Трек.mp3`, идеально подходящей для музыкальных серверов вроде **Navidrome**.

## Особенности
- 🚀 **Многопоточное скачивание** — скачивайте целые плейлисты и альбомы за секунды (настраиваемое количество потоков).
- 🎨 **Красивый интерфейс** — отрисовка прогресса и логов прямо в терминале с помощью `Rich`.
- 🟡 **Яндекс Музыка (Direct Download)** — полноценная поддержка скачивания напрямую с серверов Яндекса в оригинальном качестве (с использованием токена).
- 🔍 **Умный поиск (Фолбэк)** — если скачать напрямую не удалось, скрипт автоматически найдёт официальную аудио-версию на YouTube или Hitmo.
- 💿 **Анализ полноты альбомов** — скрипт автоматически проверяет скачанные треки, находит неполные альбомы и предлагает докачать недостающие песни!
- 🎵 **Автоматическое тегирование** — стирает рекламные водяные знаки сторонних сайтов и вшивает оригинальную обложку Яндекса, артиста, название и альбом прямо в MP3-файл.
- 📝 **Скачивание текстов (Lyrics)** — поддержка автоматического скачивания синхронизированных (LRC) и обычных текстов песен через API.
- 📂 **Идеально для Navidrome** — строгая структура папок.

## Установка

Для того чтобы утилита `hitdl` была доступна в вашей системе отовсюду (добавилась в PATH), скачайте репозиторий и выполните установку через pip:

```bash
git clone https://github.com/FHRha/HitDownload.git
cd HitDownload
pip install -e .
```

После этого вы сможете вызывать утилиту просто написав `hitdl` в любой папке вашего компьютера!

## Первоначальная настройка (Wizard)

Перед первым использованием рекомендуется запустить мастер настройки:
```bash
hitdl wizard
```
Скрипт попросит вас ввести:
1. **Путь к музыке** — куда будут скачиваться все треки (например, к папке вашего Navidrome).
2. **Genius API Токен (опционально)** — для скачивания текстов песен.
3. **Yandex Music Токен (рекомендуется)** — для прямого скачивания музыки с серверов Яндекса.

### Как получить токен Яндекс Музыки (можно без подписки Плюс!)
Даже с бесплатного аккаунта можно получать оригинальные полные треки (192 kbps):
1. Перейдите по официальной ссылке Яндекса для получения токена: 👉 [Получить токен](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d)
2. Нажмите "Войти как..." (если вы уже авторизованы в Яндексе).
3. После этого вас перебросит на пустую страницу или страницу с ошибкой. Посмотрите на адресную строку браузера — там будет ваш токен после символов `#access_token=`. 
4. Скопируйте этот длинный набор букв и цифр (до знака `&`) и вставьте в `hitdl wizard`.

> **Примечание:** Все токены безопасно сохраняются локально в скрытом файле `.env` в директории конфигурации.

## Использование

### Главное меню (Интерактивный режим)
Просто введите `hitdl` без аргументов, чтобы открыть удобное интерактивное меню:
```bash
hitdl
```

### Быстрое скачивание
Скачать один или несколько альбомов/плейлистов, передав ссылки через запятую:
```bash
hitdl get https://music.yandex.ru/playlists/lk.2a7b71ac-5150-49cf-9deb-df9b063e871e
```

**Отключение проверки альбомов:**
По умолчанию, после скачивания плейлиста скрипт проверит, не скачали ли вы "огрызки" альбомов, и предложит докачать недостающие треки. Если вы хотите пропустить этот шаг, используйте флаг `--no-albums`:
```bash
hitdl get https://music.yandex.ru/playlists/... --no-albums
```

**Регулировка скорости:**
По умолчанию используется 10 потоков. Увеличить количество (флаг `-w`):
```bash
hitdl get https://music.yandex.ru/playlists/lk.xxx -w 20
```

### Скачивание текстов (LRC)
Если вы хотите скачать тексты для уже существующих файлов в вашей библиотеке:
```bash
hitdl fetch-lyrics
```
Скрипт просканирует вашу папку с музыкой и скачает `.lrc` файлы для треков.

## Требования
- Python 3.9+
- Установленный `ffmpeg` в системе (для работы yt-dlp)
- Зависимости: `requests`, `beautifulsoup4`, `mutagen`, `rich`, `typer`, `yandex-music`, `yt-dlp`, `python-dotenv`, `lyricsgenius`, `syrics`
