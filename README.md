# HitDownload (hitdl)

HitDownload — это мощная и красивая консольная утилита для быстрого и многопоточного скачивания музыки с зеркал Hitmo (rus.hitmos.fm и др.). Она автоматически парсит страницы, скачивает треки, прописывает правильные MP3-теги (ID3) и раскладывает их по папкам в структуре `Исполнитель / Альбом / Трек.mp3`, идеально подходящей для музыкальных серверов вроде **Navidrome**.

## Особенности
- 🚀 **Многопоточное скачивание** — скачивайте целые альбомы за секунды (настраиваемое количество потоков).
- 🎨 **Красивый интерфейс** — отрисовка прогресса и логов прямо в терминале с помощью `Rich`.
- 🧠 **Умный парсинг** — поддержка нового React/Next.js движка сайта и старой HTML-версии.
- 🟡 **Яндекс Музыка** — полноценная поддержка скачивания с Яндекс Музыки (плейлисты, альбомы, треки) без токенов.
- 🔄 **Авто-зеркала** — автоматический перебор рабочих зеркал (hitmos.fm, hitmotop.com и др.), если текущее недоступно.
- 🎵 **Автоматическое тегирование** — вшивает обложку, артиста, название и альбом прямо в MP3-файл.
- 📂 **Идеально для Navidrome** — строгая структура папок.

## Установка

Для того чтобы утилита `hitdl` была доступна в вашей системе отовсюду (добавилась в PATH), скачайте репозиторий и выполните установку через pip:

```bash
git clone https://github.com/FHRha/HitDownload.git
cd HitDownload
pip install -e .
```

После этого вы сможете вызывать утилиту просто написав `hitdl` в любой папке вашего компьютера!

## Использование

### Главное меню (Интерактивный режим)
Просто введите `hitdl` без аргументов, чтобы открыть удобное интерактивное меню:
```bash
hitdl
```

### Быстрое скачивание
Скачать один или несколько альбомов/плейлистов, передав ссылки через запятую:
```bash
hitdl https://rus.hitmos.fm/album/7132879,https://music.yandex.ru/playlists/lk.2a7b71ac-5150-49cf-9deb-df9b063e871e
```

**Регулировка скорости:**
По умолчанию используется 10 потоков. Для больших плейлистов или быстрого интернета вы можете увеличить их количество с помощью флага `-w`:
```bash
hitdl https://music.yandex.ru/playlists/lk.xxx -w 20
```

### Настройка (Wizard)
Настроить путь к папке, куда будет скачиваться музыка (например, к папке вашего Navidrome):
```bash
hitdl wizard
```

## Использование с Docker (Navidrome)

Если ваш Navidrome работает в Docker, вы можете легко пробросить папку с музыкой в `hitdl` (если запускаете скрипт в контейнере) или просто настроить `hitdl` локально на ту же папку.

### Способ 1: Локальный запуск (Рекомендуется)
Если папка Navidrome примонтирована к вашей файловой системе (например, `./music:/music`), просто выполните `hitdl wizard` и укажите абсолютный путь к папке `./music` на вашем хосте.

### Способ 2: Запуск HitDownload в Docker
Вы можете собрать образ утилиты и запускать её внутри Docker, примонтировав папку с музыкой.

1. Соберите образ:
```bash
docker build -t hitdownload .
```
2. Запустите скачивание (замените `/path/to/navidrome/music` на путь к вашей музыке):
```bash
docker run --rm -it -v /path/to/navidrome/music:/music -e MUSIC_DIR=/music hitdownload https://rus.hitmos.fm/album/7132879
```
